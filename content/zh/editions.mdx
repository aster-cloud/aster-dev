# 版本

Aster 提供三个版本。**语言与引擎在三者间完全一致**——区别在于由谁运行、以及有哪些能力为你托管。

## 一览

| | 开源版 | 云版（SaaS） | 企业版 |
| --- | --- | --- | --- |
| **由谁运行** | 你，在自己的机器上 | 我们，在 `aster-lang.cloud` | 你，在自己的 VPC / 集群 |
| **许可证** | Apache-2.0 | 订阅 | 订阅 + 永久回退授权 |
| **适合** | 构建、学习、嵌入 | 想要托管多租户的团队 | 受监管、数据驻留、气隙隔离场景 |
| **开始** | `npm i @aster-cloud/aster-lang-ts` | [aster-lang.cloud](https://aster-lang.cloud) | 联系销售 |

## 语言与引擎

每个版本都附带完整的语言和两套运行时——语言层面不做任何保留。

| | 开源 | 云 | 企业 |
| --- | :---: | :---: | :---: |
| 多语言 CNL（en / 中文 / Deutsch / हिन्दी） | ✅ | ✅ | ✅ |
| Java/Truffle 参考引擎 | ✅ | ✅ | ✅ |
| TypeScript 引擎（浏览器/Node） | ✅ | ✅ | ✅ |
| LSP / 编辑器扩展 | ✅ | ✅ | ✅ |
| 自定义词典编写 | ✅ | ✅ | ✅ |

## 策略执行与治理

| | 开源 | 云 | 企业 |
| --- | :---: | :---: | :---: |
| 本地求值 | ✅ | ✅ | ✅ |
| 托管 REST / GraphQL API | — | ✅ | ✅ |
| 版本管理 + 回滚 | 自托管 | ✅ | ✅ |
| 决策轨迹 / 回放 | ✅ | ✅ | ✅ |
| 审计日志 + 哈希链 | 自托管 | ✅ | ✅ |
| 多租户 + RBAC | — | ✅ | ✅ |
| 数据驻留 / 气隙隔离 | — | — | ✅ |

> 语言本体**以 Apache-2.0 开源**。云版与企业版围绕同一套引擎，额外提供托管、治理与运维能力。
